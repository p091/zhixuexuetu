# 智汇学途 项目介绍

## 一句话介绍
智汇学途是一套面向高校场景的学习资源流通平台，将资料上传、论坛交流、电子教材、二手教材和积分激励整合到同一个系统中。

## 项目背景
校园学习资料长期分散在班群、聊天记录、网盘链接和个人设备里，查找效率低，沉淀能力弱；二手教材和优质笔记缺少稳定流通入口；同学之间虽然有分享意愿，但缺少持续激励机制。

## 解决方案
智汇学途围绕“资源汇聚、交流协作、教材流通、激励闭环”四条主线搭建完整使用链路：

1. 学习资料统一上传、分类、检索和下载。
2. 校园论坛承接问题讨论、经验分享和组队协作。
3. 二手教材与电子教材形成线上互补资源库。
4. 用户上传资源可获得积分，积分可在商城中兑换学习用品与校园权益。

## 核心功能
1. 资源共享：支持按分类浏览资料，下载过程有进度反馈，新上传内容自动进入列表。
2. 校园论坛：支持帖子浏览、点赞互动和话题聚合，增强学习协作氛围。
3. 上传中心：提交资料后自动发放积分，形成正向激励。
4. 二手教材：提供教材流转入口，降低学习成本。
5. 电子教材：沉淀高频数字化学习内容，提升获取效率。
6. 积分商城：将用户贡献与可感知回报直接连接，提升平台活跃度。

## 产品亮点
1. 完整闭环：从上传、展示、下载到积分兑换，形成可连续演示的产品链路。
2. 轻量稳定：纯前端架构，本地持久化存储，部署快、演示稳定、无需依赖后端环境。
3. 交互直观：上传、下载、兑换、点赞均有即时反馈，产品体验接近真实业务系统。
4. 校园适配：功能全部围绕学生常见学习场景展开，使用路径清晰。

## 技术实现
1. 前端框架：React 18 + TypeScript + Vite。
2. 组件体系：Ant Design。
3. 状态管理：Zustand 持久化存储。
4. 页面体验：Framer Motion + CountUp 实现过渡与数字动画。
5. 部署方式：构建后可直接部署到 GitHub Pages 或 Cloudflare Pages。

## 应用价值
1. 对学生：更快找到资料、更低成本获取教材、更方便参与学习协作。
2. 对校园社群：沉淀高质量共享内容，减少资料反复分发成本。
3. 对项目落地：功能边界清晰，后续可平滑接入真实后端、账号体系和审核机制。

## 路演演示顺序
1. 首页展示系统整体结构和核心模块。
2. 进入论坛页演示互动与点赞反馈。
3. 进入资源页演示分类筛选与下载进度。
4. 进入上传中心演示上传成功、积分增加、资源入库。
5. 进入积分商城演示积分兑换和实时扣减。

## 60 秒口播版
智汇学途聚焦校园里最常见的一个问题，就是学习资源分散、共享效率低。我们把资料上传、资源下载、论坛互动、二手教材流通和积分激励整合到一个系统里，形成了完整的产品闭环。用户上传资料可以获得积分，积分又可以在商城中兑换学习用品和校园权益，这样既提升了资源沉淀效率，也增强了同学之间的持续参与度。项目采用纯前端架构实现，部署简单、运行稳定，非常适合前期验证和校园场景落地。
